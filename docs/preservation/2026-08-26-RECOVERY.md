## Restoring a box

1. `aws ec2 create-volume --snapshot-id <snap> --availability-zone <az> --volume-type gp3`
2. Launch the instance type from the AMI pin above, or attach the volume as root.
3. Re-apply user-data from `userdata_<id>.sh` if launching fresh.
4. Re-attach the IAM instance profile named in `instances_summary.json`.

## Teardown order (Codex-verified)

Snapshots are independent of their source volumes: deleting a volume does NOT
affect a snapshot already taken from it. All seven volumes have
DeleteOnTermination=true, so terminating destroys the disk — snapshot first.
The three CFN-managed instances must be removed via stack update/destroy, not
`terminate-instances`, or the stack drifts and a later deploy may recreate them.

### How teardown was done
- specdec, quant, inf2-b, us-east-2 spot: `terminate-instances` (not CFN-managed)
- neuron-pipelines-trn1, neuron-pipelines-inf2, aps1 autoshutdown:
  `delete-stack` on NeuronPipelinesTrainium, NeuronPipelinesInferentia,
  Ec2AutoshutdownStack — avoids the CloudFormation drift that manual
  termination would have caused.
- **NeuronPipelinesBase was NOT deleted** — it owns the artifacts bucket
  `neuron-pipelines-artifacts-600627330911` and the `neuron-pipelines-monthly` budget.

### Trap hit during teardown
Terminating us-east-2 `i-085d18f0cbf836630` immediately triggered a REPLACEMENT
instance `i-0e9da742ceabd77e1` with a fresh 50 GB volume. Cause: a **persistent**
spot instance request `sir-ngqfdjzk` from TrainiumSpotStack. Fix is order-sensitive:
cancel the spot request FIRST, then terminate, or it respawns indefinitely.
Request cancelled, replacement terminated.

### Still live, deliberately untouched
- `TrainiumSpotStack` (us-east-2) — already drifted; its recorded instance
  i-02eda0a14d60f64c2 no longer exists. VPC/IGW/keypair only, no cost.
- `NeuronPipelinesTrainium2` (sa-east-1) — **AutoScalingGroup
  NeuronPipelinesTrainium2-Trn2AsgASG56F8472A-WzMFVvw2ikkW has DesiredCapacity=1

  on capacity. It WILL launch and bill the moment sa-east-1 has trn2 capacity.
  Left at 1 on the assumption this is an intentional capacity catcher.
  Set DesiredCapacity=0 to disarm.
